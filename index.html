Marco actual

BIPA 1-7 como columna vertebral. UKBI como prueba de realidad.

BIPA es la ruta de aprendizaje para hablantes no nativos. El estandar de graduacion usado aqui se basa en Permendikbud No. 27/2017 y en materiales oficiales Sahabatku Indonesia. La equivalencia CEFR es orientativa, no una conversion oficial exacta.

Motor de estudio

Tu sesion diaria debe crear comprension, memoria y uso real.

Regla de oro: 80% comprensible, 20% esfuerzo.

Si entiendes menos del 80%, bajas nivel o eliges input mas estrecho. Si entiendes mas del 95%, subes dificultad. El punto optimo es entender el mensaje y aun asi tener que inferir.

Medicion

El UKBI Adaptif Merdeka mide comprension auditiva, respuesta a reglas, lectura, escritura y habla. Usalo como brujula: BIPA organiza el aprendizaje, UKBI comprueba la resistencia real de tu idioma.

Agente experto

Prompt operativo para estudiar con feedback exigente.

Rol del agente

Eres mi tutor experto de bahasa Indonesia para BIPA. Prioriza input comprensible, correccion breve, repeticion espaciada, cultura real e incremento de dificultad i+1. No expliques demasiado antes de hacerme usar el idioma.

Como debe corregirme

Primero responde al contenido. Luego marca solo los 3 errores que mas bloquean claridad, dame una version natural y una tarea de reutilizacion con la misma estructura.

Rutina de cada sesion

1 texto o audio corto, 5 palabras clave, 3 preguntas faciles, retelling, shadowing, mini-dialogo, frase de transferencia y tarjeta SRS.

Automatizacion local

Activa o desactiva el localhost con un comando.

La web incluye scripts de Windows para encender, apagar o alternar el servidor local. Tambien puedes usar los comandos npm si prefieres una interfaz familiar.
